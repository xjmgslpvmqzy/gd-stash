## Overview

GD Stash is a comprehensive external inventory manager for Grim Dawn, providing stash management across multiple stash pages, item crafting from components, database browsing of all items and their drop sources, and character save editing for attributes and devotion points. It supports all Grim Dawn expansions including Forgotten Gods.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **GD Stash** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Extended Stash** | Manage unlimited stash pages beyond Grim Dawn's built-in limit |
| **Item Crafting** | Craft any item from components using the full item database |
| **Database Browser** | Browse every Grim Dawn item with drop locations and stats |
| **Character Editor** | Edit attribute points and devotion point allocation per character |
